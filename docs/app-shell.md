# AppShell

`AppShell` legt die Seitenhöhe fest. Varianten: `page` (scrollende Seite), `viewport` (Karte, eine Viewport-Höhe), `center` (Login).

Die Komponente ist in `@veit/react-controls` exportiert und enthält keine Produkttexte. Hochwasserdienst importiert sie in `apps/web/src/components/AppShell.tsx`.
